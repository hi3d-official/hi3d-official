# Hi3D

**AI-powered 3D generation.**

[International / 国际站](http://hi3d.ai/) · [China / 国内站](https://www.hi3d.cn/)

Welcome to the official Hi3D GitHub account. Hi3D is an AI-powered 3D generation platform for creators and developers.

## Open source & developer resources

We plan to share selected models and code, along with SDKs, API examples, and integrations that help the community explore and build with Hi3D.

- **Models & code** — selected model releases, research code, and supporting tools.
- **SDKs & API examples** — resources for integrating Hi3D into your applications.
- **Integrations** — tools for bringing Hi3D into creative and development workflows.

Projects will be added as they become available. Please refer to each repository for its documentation, release status, and license terms.

## 关于 Hi3D

Hi3D 是面向创作者与开发者的 AI 3D 生成平台。这里是 Hi3D 官方 GitHub 账号。

我们将在这里陆续开源部分模型与代码，并分享 SDK、API 调用示例及相关集成工具，帮助社区探索 3D 生成技术，将 Hi3D 接入创作与开发流程。

各项目的使用方式、发布状态与许可范围，请以对应仓库的文档和许可证为准。
